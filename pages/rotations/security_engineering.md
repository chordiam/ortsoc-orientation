# Security Engineering Rotation

> Research draft for the ORTSOC Initial Orientation Website. Pending review by the Security Engineering Rotation Lead. No client information is to be disclosed.

## What Security Engineering Does

In the Security Engineering rotation, you will learn how to maintain and improve the systems and infrastructure that support ORTSOC operations. This includes working with hardware, software, security monitoring tools, and client sensors to help ensure that ORTSOC systems function properly.

Unlike rotations that focus primarily on investigating threats or assessing security risks, Security Engineering focuses on the infrastructure and technology that make those activities possible.

**What you will be evaluated on:**

- Maintain security systems and support ORTSOC operations.
- Monitor systems and identify areas for improvement.
- Identify and correct faulty or malfunctioning security rules.
- Build and maintain client sensors.
- Apply patches and updates during scheduled maintenance or urgent situations.
- Understand how client environments integrate with ORTSOC systems.
- Assist with staff-led projects.
- Demonstrate good written and verbal communication skills.

## Tools You Will Use

| Tool | What it's for |
|---|---|
| **Network TAPs** | Allow network traffic to be observed by monitoring systems. |
| **Zeek** | Analyzes network traffic and generates logs that help analysts understand network activity. |
| **Suricata** | Monitors network traffic and identifies suspicious activity using detection rules. |
| **Elastic** | Collects, processes, stores, and analyzes security data. |
| **WireGuard** | Provides encrypted network connections between systems. |
| **Bash** | A command-line shell used to interact with Linux systems. |
| **Vim** | A text editor used to edit files through the command line. |
| **Ansible** | Helps automate system configuration and administrative tasks. |
| **YAML** | A format commonly used for configuration files. |
| **AlmaLinux** | A Linux operating system used in sensor installation exercises. |

These tools and technologies are introduced during orientation. You are not expected to be familiar with all of them before starting the rotation.

## What to Expect

Security Engineering involves both hardware and software, so you will work with different parts of the systems that support ORTSOC.

- **Reading and hands-on practice:** You will learn about the tools, technologies, and hardware used during the rotation.
- **Troubleshooting:** You may need to identify why a system, application, or security rule is not working as expected.
- **Understanding components:** Knowing why a tool or piece of hardware is used is just as important as knowing its name.
- **Working with others:** Some activities involve group work, but you should understand the overall process.
- **Individual evaluations:** You will need to demonstrate your own understanding of hardware and software concepts.

## Getting Started

The rotation orientation introduces the basic knowledge needed to work with ORTSOC infrastructure and client sensors.

**Getting started checklist:**

1. Read the Security Engineering overview and expectations on Canvas.
2. Review the orientation materials covering client sensors and their software.
3. Become familiar with Zeek, Suricata, Elastic, and network TAPs.
4. Review the basics of security detection rules and rule exceptions.
5. Practice basic Linux command-line skills, including Bash and Vim.
6. Learn the introductory concepts behind Ansible and YAML.
7. Review common computer hardware components and their purposes.
8. Complete the assigned knowledge checks and prepare for the sensor evaluations.

Refer to Canvas for the current assignments, required resources, and evaluation instructions.

## Client Sensors and Security Rules

One of the main areas covered during Security Engineering orientation is understanding client sensors and security detection rules.

### Client Sensors

A client sensor is a system used to collect and analyze network traffic so that security analysts can monitor activity and identify potential threats.

During orientation, you will learn about technologies such as network TAPs, Zeek, Suricata, and Elastic. These technologies help collect, analyze, and organize network information used in security monitoring.

You will also become familiar with the hardware and software involved in client sensors through hands-on exercises.

### Security Detection Rules

Detection rules help monitoring systems identify activity that may indicate a security threat. During orientation, you will learn about Suricata rules, Elastic detection rules, and rule exceptions.

You will also learn why detection rules sometimes need to be adjusted to reduce false positives and improve the accuracy of security monitoring.

Detailed sensor configurations, installation procedures, and rule management instructions are covered in the official Canvas materials rather than this website.

## Hardware and Software Evaluations

The Security Engineering orientation includes hands-on exercises to help students become familiar with the hardware and software used in client sensors.

### Hardware Evaluation

Students practice identifying and installing computer components, including the CPU, RAM, SSDs, graphics card, and network interface card.

During the individual evaluation, you will be expected to identify the components, explain their purposes, and demonstrate an understanding of their proper installation.

### Software Evaluation

Students work in groups to become familiar with installing and configuring sensor software, including AlmaLinux, Zeek, and Suricata.

After the group exercise, students are evaluated individually on their understanding of the software, its purpose, and how it supports network monitoring.

Refer to the official Sensor Build and Software Install Packets for detailed instructions.

## Beginner Tips

- **Review basic hardware components.** Be comfortable identifying the CPU, RAM, storage devices, motherboard, and network components.
- **Understand Zeek and Suricata.** Know their general purposes and how they support network monitoring.
- **Practice basic Linux commands.** Familiarity with Bash and Vim can make working with Linux systems easier.
- **Focus on understanding rather than memorizing.** Knowing why a tool or component is used will help when troubleshooting.
- **Take notes during exercises.** Record what you learned and any problems you encountered without including sensitive system information.
- **Communicate with your group.** Even when tasks are divided among students, make sure you understand the overall exercise.
- **Ask a mentor when you are unsure.** Refer to Canvas and official instructions rather than guessing about system configurations.
